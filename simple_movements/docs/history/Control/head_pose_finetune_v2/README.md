# 头姿第二轮调整

这是独立实验目录，从第一版410轮继续，原400轮、第一版410轮和当前统一控制器均保留。

调整目的：进一步减少安静站立和停车后的剩余侧倾，同时给运动保留必要的摆头范围。

- 安静阶段：head_yaw相对教师目标允许±4°，head_roll允许±3°。
- 运动阶段：保留第一版的yaw±9.27°、roll±8.55°。
- 由标定物理指令的活动度平滑混合两种范围：`a=smoothstep(clamp(max(||T_xy||/0.03, |T_wz|/0.15),0,1))`，`band=quiet_band+(moving_band-quiet_band)*a`。输入零指令时使用安静范围，过渡指令连续变化，不增加未来信息或隐藏状态。
- roll位置权重0.12→0.18，roll速度权重0.01→0.015；yaw及俯仰权重保持第一版，仍使用柔和越界代价，没有锁头或覆盖输出角度。
- 教师安静段99%偏差约yaw2.21°、roll1.67°，均在新范围内。
- 这是R8基础奖励加第二版头姿代价，替换第一版代价，不重复叠加两套头姿惩罚。

已从410轮迁移并重新校准critic1000次（原64k500次、410保存的学生回放500次），逐张量确认策略/世界模型在校准阶段未变化；再以策略学习率0.000025进行411–420轮短训练。正式原网络、32步想象与SuperMimic更新方法保留。配置哈希隔离新旧目标，不直接混用旧critic。

`config.json`为配置；`prepared/checkpoint_0410_head.pt`为校准起点；`short_train/checkpoint_0420.pt`为短训候选；`baseline410.json`、`comparison.json`记录成对评估。reward_validation.json验证安静范围比运动更严格、目标处不扣分、正负对称且梯度有限朝向回正。

候选判定门槛：原完整42场景不降且达到42/42，附加运动轴25%相对误差子集数不降，站立/停车roll平均绝对目标偏差各至少减少25%，全流程yaw误差不明显增大。头姿统计只取存活样本，不能因提前摔倒样本变少而判为改善。当前统一控制器不自动替换。

第一版的within_soft_band_fraction仍按统一运动范围统计，以方便历史对照；第二版安静约束效果应结合standing/stopped角度与偏差读取，不能把该辅助比例当成±3°合格率。


## 已完成的短训练结果

|指标|410轮新复测|420轮|
|---|---:|---:|
|完整起停|42/42|42/42|
|附加运动轴相对误差25%子集|34/42|36/42|
|全流程yaw平均绝对目标偏差°|4.13|3.47|
|全流程roll平均绝对目标偏差°|9.39|5.73|
|初始站立yaw平均绝对目标偏差°|0.18|1.57|
|初始站立roll平均绝对目标偏差°|7.07|2.12|
|运动yaw平均绝对目标偏差°|4.06|3.92|
|运动roll平均绝对目标偏差°|10.70|8.86|
|停车后yaw平均绝对目标偏差°|6.20|3.80|
|停车后roll平均绝对目标偏差°|9.37|3.77|

初始站立head_roll实际均值8.98°→4.03°；停车后11.28°→5.68°。

固定42场景候选门槛通过：True。仍有运动中的摆动及少量剩余侧倾；柔和约束不等于硬锁头，也不证明任意场景通过。原400、410文件未覆盖，现有统一控制器未替换。

对照原始数据为baseline410.json及short_train/evaluations.jsonl；来源410重新复测的附加25%子集为34，与第一版当时35有轻微浮点动力学波动，本次使用34作成对基线，不覆盖第一版正式记录。
