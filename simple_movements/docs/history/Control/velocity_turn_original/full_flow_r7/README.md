### 原因及已修复内容

原R7奖励按教师实际均速标定目标，但使用 `exp(-短窗口误差/scale)` 跟踪。目标变小时，站立也能得到较高平移得分；真实教师仍承担步态摆动、漂移和动作成本。对完整63条教师轨迹复核，21组中4组平均奖励低于站立，包括新加入的后退-0.17。理想恒速状态的排序测试没有覆盖这种真实步态损失，不能作为充分验证。

R8在已有跟踪得分上增加**请求方向的有符号进展门控**。沿用当前/过去8步形成的0.16秒因果速度，没有增加未来观测、阶段标签或网络状态。

```text
T = teacher_response(raw_command)       # 标定物理目标，策略输入仍是原指令
p_v = dot(v_avg_xy, T_xy) / max(norm(T_xy), 0.001)
a_v = smoothstep(clamp(norm(T_xy)/0.02, 0, 1))
g_v = 1-a_v + a_v*clip(p_v/max(norm(T_xy),0.02), -1, 1)

p_w = wz_avg * sign(T_wz)
a_w = smoothstep(clamp(abs(T_wz)/0.10, 0, 1))
g_w = 1-a_w + a_w*clip(p_w/max(abs(T_wz),0.10), -1, 1)

S_v_R8 = S_v_R7 * g_v
S_w_R8 = S_w_R7 * g_w
smoothstep(x) = x²*(3-2x)
```

- 对21组实际运动端点，请求运动的轴处于完整门控区。站立时该运动轴进展为0，因此不再仅凭较小绝对误差获得运动奖励；沿正确方向接近目标时获得奖励，反向运动的该项为负。
- 进展比例超过目标后门控保持1，原速度误差项仍降低过快运动得分，避免无限追求更大速度。不是无方向的“动起来就加分”。
- 不要求运动的轴门控为1：直行仍约束yaw漂移，原地转仍约束平面漂移。弧线同时要求前进和转向方向进展。
- 物理目标近零时门控平滑过渡；目标完全为0时g_v=g_w=1，原站立/停车及瞬时振荡惩罚保持原样。没有通过取消停车约束换取运动。
- 原跟踪权重、姿态0.5、动作0.005、动作变化0.01、关节越限、终止扣1、停滞以及停车稳定项保留。附加错速惩罚仍各0.15，但现在反向得分可为负，最大理论总扣分上界记录为0.60；自适应重置中该惩罚的归一化分母同步由0.30调整为0.60，原采样方法/配额不变。

真实环境、离线critic预热和想象更新都通过同一个奖励函数使用上述得分。磁盘历史reward列不改写，加载预热时按R8重算；世界模型仍学习真实物理转移。原SuperMimic网络、32步想象、GAE、target critic与联合更新方法不变。
