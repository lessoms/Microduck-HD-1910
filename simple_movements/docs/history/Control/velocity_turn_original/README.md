### 原因及已修复内容

原R7奖励按教师实际均速标定目标，但使用 `exp(-短窗口误差/scale)` 跟踪。目标变小时，站立也能得到较高平移得分；真实教师仍承担步态摆动、漂移和动作成本。对完整63条教师轨迹复核，21组中4组平均奖励低于站立，包括新加入的后退-0.17。理想恒速状态的排序测试没有覆盖这种真实步态损失，不能作为充分验证。

R8在已有跟踪得分上增加**请求方向的有符号进展门控**。沿用当前/过去8步形成的0.16秒因果速度，没有增加未来观测、阶段标签或网络状态。

```text
T = teacher_response(raw_command)       # 标定物理目标，策略输入仍是原指令
p_v = dot(v_avg_xy, T_xy) / max(norm(T_xy), 0.001)
a_v = smoothstep(clamp(norm(T_xy)/0.02, 0, 1))
g_v = 1-a_v + a_v*clip(p_v/max(norm(T_xy),0.02), -1, 1)

p_w = wz_avg * sign(T_wz)
a_w = smoothstep(clamp(abs(T_wz)/0.10, 0, 1))
g_w = 1-a_w + a_w*clip(p_w/max(abs(T_wz),0.10), -1, 1)

S_v_R8 = S_v_R7 * g_v
S_w_R8 = S_w_R7 * g_w
smoothstep(x) = x²*(3-2x)
```

- 对21组实际运动端点，请求运动的轴处于完整门控区。站立时该运动轴进展为0，因此不再仅凭较小绝对误差获得运动奖励；沿正确方向接近目标时获得奖励，反向运动的该项为负。
- 进展比例超过目标后门控保持1，原速度误差项仍降低过快运动得分，避免无限追求更大速度。不是无方向的“动起来就加分”。
- 不要求运动的轴门控为1：直行仍约束yaw漂移，原地转仍约束平面漂移。弧线同时要求前进和转向方向进展。
- 物理目标近零时门控平滑过渡；目标完全为0时g_v=g_w=1，原站立/停车及瞬时振荡惩罚保持原样。没有通过取消停车约束换取运动。
- 原跟踪权重、姿态0.5、动作0.005、动作变化0.01、关节越限、终止扣1、停滞以及停车稳定项保留。附加错速惩罚仍各0.15，但现在反向得分可为负，最大理论总扣分上界记录为0.60；自适应重置中该惩罚的归一化分母同步由0.30调整为0.60，原采样方法/配额不变。

真实环境、离线critic预热和想象更新都通过同一个奖励函数使用上述得分。磁盘历史reward列不改写，加载预热时按R8重算；世界模型仍学习真实物理转移。原SuperMimic网络、32步想象、GAE、target critic与联合更新方法不变。

## 历史版本R5：对齐教师实际运动响应

### 数据依据与标定规则

- 使用原始 `source/forward` 与 `source/turns` 的63条恒定指令教师轨迹，每档3次，每次取3–7秒完整200步，共12600个稳定样本。要求整条轨迹无物理失败、窗口无终止/非有限、最大倾角≤20°；连续变速/换向的9条轨迹不作为固定速度标定。

- 直行的前后速度、纯转向的yaw响应按输入节点分段线性插值；超出测量轴端点时不继续外推。绝对响应<0.002m/s或<0.01rad/s的近零值归零。不是把所有指令统一乘0.5。

## 实现方法

```text
当前摇杆指令 [vx, 0, wz] + 10帧本体历史
                    ↓
                  策略
                    ↓
             14维关节位置目标
                    ↓
当前291维物理状态 + 执行动作 + 18维环境参数
                    ↓
                 世界模型
                    ↓
预测下一物理状态 → 速度/转向奖励 + 存活估计
                    ↓
32步可微想象 + target critic末端值 → 更新策略
                    ↓
          GAE目标 → 更新critic
```

世界模型不直接接收摇杆，学习的是动作引起的物理变化；策略学习如何响应目标速度。策略保留480维本体历史，目标编码器仍为440维：把**当前**3维速度指令重复放进10个44维块，其他位置为零，不输入未来摇杆值、时间、参考位置或参考关节动作。

`reference.npz` 是物理重置快照、命令计划和干净初始动作标签的库，不是要求机器人复现的固定空间路径。帧索引只用于数据管理、采样和训练时的命令安排。Critic保留原753维输入，固定参考根部误差的4维置零，避免虚构路径目标。

`velocity_joint_recipe.py` 的 `VelocityTrainer` 直接继承原 Trainer 的 `warmup`、`world_update`、`critic_update`、`train`、`imagine`、`imagined_observation` 等优化方法；任务接口、actor分组和真实评估由适配器提供。

来源位于 `source/forward`、`source/turns`，联合来源清单是 `source/dataset_manifest.json`。清理时只移动了路径并更新来源元数据；现有 `reference.npz` 和64,000条 `transitions.npz` 的文件SHA256未改变。

| --- | --- |
| 前后速度 | vx = 0、±0.05、±0.10、±0.15、±0.18、±0.22 m/s |

## 历史训练版本R4：零指令瞬时速度与振荡约束

```text
u = clamp(max(norm(command_xy)/0.03, abs(command_wz)/0.15), 0, 1)
gate = 1 - u²*(3-2*u)
E(x, scale) = sqrt(1 + sum((x/scale)²)) - 1
instant_cost = 0.5*E(v_instant-command_xyz, 0.03)
             + 0.5*E(w_instant-[0,0,command_wz], 0.30)
oscillation_cost = 0.25*E(v_instant-v_average, 0.03)
                 + 0.25*E(w_instant-[0,0,wz_average], 0.30)
r_R4 = r_R3 - gate*(instant_cost + oscillation_cost)
```

这里v/w为机体系三维速度，command_xyz=[vx,vy,0]。零指令gate=1，既惩罚实际瞬时运动，也惩罚相对因果平均速度的摆动；往返抵消不再免罚。roll/pitch角速度也纳入约束。线速度指令达到0.03 m/s或yaw达到0.15 rad/s时gate=0，正常运动奖励保持R3；两者都更小时平滑过渡，避免突然切换。门控只由请求指令决定，策略不能靠自己运动来关掉惩罚。不使用未来状态、额外滤波记忆或新增网络输入。

E是平滑的近零二次、较大误差近线性惩罚，梯度有限，没有裁剪到完全无梯度的平台。已有姿态、动作平滑、关节越限和终止惩罚全部保留。若新约束影响小幅指令起步，必须通过真实低速与归零测试评估，不能仅凭奖励排序宣称训练成功。

## 失败原因：旧奖惩机制详解与R3修复

旧任务适配器的奖励是本任务新增的，不是SuperMimic原固定参考奖励。旧公式（速度单位m/s，yaw单位rad/s）为：

```text
S_v = exp(-||瞬时v_xy - command_xy||² / 0.08²)
S_w = exp(-(瞬时wz - command_wz)² / 0.50²)
r = 2*S_v + 0.5*S_w + 0.5*posture
    - 0.15*(1-S_v) - 0.15*(1-S_w)
    - stall_v - stall_w
    - 0.005*mean(action²) - 0.01*mean((action-previous)²)
    - sum(joint_limit_violation²) - terminated
```

问题在于“原地转动”仍有抬脚、左右摆体和重心转移，瞬时平移速度不为零。旧奖励把这些摆动当作严重错速，且平移权重是转向的4倍；验收却看3–7秒平均速度。站住能稳定拿满平移项，正确方向的转动反而损失更多奖励。停滞扣分只有0.10，无法抵消这部分收益。

用同一目标指令重算已记录的真实教师轨迹和站立轨迹：目标wz=+0.5时，教师平均实际wz约+0.302，平均vx/vy约-0.009/-0.010，但瞬时平面速度RMS约0.144，大于0.08奖励宽度。奖励分解如下（3–7秒每步均值）：

| 项目 | 教师转动 | 保持站立 | 影响 |
| --- | ---: | ---: | --- |
| 加权平移奖励 | 0.617 | 2.000 | 转动少得1.383 |
| 加权yaw奖励 | 0.376 | 0.184 | 转动只多得0.192 |
| 姿态奖励 | 0.498 | 0.492 | 差异很小 |
| 额外错速扣分 | -0.141 | -0.095 | 再次不利于摆体 |
| 停滞扣分 | -0.002 | -0.100 | 免罚只补回约0.098 |
| 总奖励（含其余项） | 1.347 | 2.480 | 不转明显更划算 |

目标-0.5时也为1.295对2.481；±0.75同样偏向站立。后退-0.18仅为0.826对0.756，优势很弱。因此不是简单“惩罚不够多”，而是跟踪时间尺度与运动任务权重冲突。动作平滑、关节越限、终止扣分仍有必要，没有证据支持直接删除它们。这个排序错误已被记录轨迹证实，但它不是全部失败因素的因果证明：教师低速覆盖差、BC仅过2/20、32步模型/末端价值误差仍需后续验证。

### 已实施的修改（windowed_twist_r3）

实现位于 `../velocity_joint_recipe.py`，保持原SuperMimic网络、32步想象、target critic、GAE、更新次数及物理随机化不变。

1. 重用原8步pose_history：平移由当前位置减8步前位置，除以0.16秒并旋转到当前机体系；yaw由包裹到[-π,π]的角度差除以0.16秒。只使用当前及过去状态，不增加未来指令、隐藏滤波状态或网络输入。真实环境、critic和想象使用同一奖励函数与窗口；年龄不足8步时回退瞬时速度。
2. 将平方Gaussian改为距离指数，减少大误差区得分和梯度过早接近零：`e_v=sqrt(||v_avg-command_xy||²+1e-6)-0.001`，`e_w=sqrt((w_avg-command_wz)²+1e-6)-0.001`，得分分别为`exp(-e_v/0.10)`与`exp(-e_w/0.50)`。原地转的e_v再减0.03并截断到非负，限制平均漂移，避免惩罚必要摆动；零指令没有这个死区。
3. 按请求指令选择平移/yaw权重：直行2.0/0.5、原地转0.5/2.0、同时运动及零指令1.5/1.5。权重不依赖预测运动状态，策略不能通过自己走偏切换权重。仅做时间平均还不足以修复已记录转向轨迹的排序，因此同时调整任务权重。
4. 保留姿态0.5、错速各0.15、8步停滞各最大0.10、动作0.005、动作变化0.01、关节越限和终止扣1。完整新奖励为`a*S_v+b*S_w+0.5*posture`减上述各项；没有增加无条件“动起来”奖励，反向和大漂移仍会失分。
5. checkpoint及collection配置记录reward_version；与旧奖励不匹配的预热模型不能混用。原64,000条物理转移和参考数据继续复用，训练器按当前函数重新计算学习目标，磁盘旧reward列仅是历史记录。必须重新做世界模型/critic与actor预热，输出到独立reward_r3目录。
6. 修正评估统计：未进入速度窗口时RMSE/均速为null而不是0，并记录速度样本数；停稳必须实际覆盖最后100步且存活。无速度样本的模型排序误差使用有限大值。记录首次失败时间和原因。验收阈值不放宽，仍每10轮保存并评估20场景。

### 本次300轮失败原因详细分析（归档）

### 失败一：平均速度奖励漏掉了瞬时振荡，停稳失败（直接证据）

末轮原评估15个存活场景全部运动均速通过，却无一满足末两秒逐步停稳。额外复测同样完整0/20、存活15/20。归零后存活样本三维角速度模长均值0.541 rad/s、峰值3.347，59.7%样本超过0.3门槛；线速度模长均值0.0132 m/s，7.1%超过0.03门槛。角速度各轴RMS为0.130, 0.140, 0.713 rad/s，主要是yaw振荡；带符号均值仅-0.001, 0.001, -0.019。

R3的0.16秒位移/角度差奖励成功减轻了行走摆动惩罚，却也允许快速往返运动在窗口内相互抵消。零指令下该批抖动样本仍平均得3.394/步，而理想静止且无动作成本的上限为3.5/步。姿态项奖励直立与高度，不直接限制角速度；动作变化惩罚仅0.01，无法保证身体平静。这是奖励与停稳验收仍不一致的明确证据，不能通过放宽验收掩盖。此前14组离线排序测试只比较运动与站立，未验证零指令下“安静站立”与“均速为零的振荡”排序，测试覆盖不足。

不能完全取消平均速度奖励，否则会重新出现惩罚必要步态摆动的问题。下一次应保留运动阶段平均跟踪，同时在零/近零指令加强瞬时三维线/角速度及振荡能量约束，增加运动到归零的稳定停住验证。应先离线比较安静站立、抖动、正确行走、正确转向和反向，确认排序，再做短训练；本次未实施这些新修改。

## 失败机制及证据边界

### 1. 大部分阶段收敛到站立或运动幅度不足

170、180、200、220轮均有20/20存活，但只完整通过两个零指令。220轮前进目标0.2实际约0.00054，后退目标-0.2实际约+0.00063，左右转实际约+0.0028/-0.0061 rad/s，基本原地站住。280轮右转才出现部分有效运动；前进目标0.2实际0.020，后退目标-0.2实际-0.0003，左转目标0.6实际0.102。不能把较高存活率与停稳率当作已学会运动。

R4新增稳定惩罚只在近零指令开启，|vx|≥0.03或|wz|≥0.15时gate=0。因此不能声称恒定运动阶段直接受到新增stop_cost惩罚。起步、减速、归零的价值仍与零指令稳定目标耦合，可能使策略偏保守；现有证据还不足以确定具体权重的因果贡献。离线验证“教师轨迹奖励高于站立”只证明特定记录行为的排序，不证明从当前弱策略能找到该步态，也没有覆盖完整学习中的模型/critic误差。

### 2. 预热没有提供可靠运动接管能力

Actor预热八次完整通过均2/20，只有零指令。按完整通过、存活、误差择优选250次，其存活8/20；这确实加载了选中候选，而不是错误加载最后一次。最好候选本身仍缺乏运动能力。联合阶段从这种初始化学习前后+转向+停车，存在较大探索与动态接管难度。

来源教师小yaw指令几乎不转，原64k加噪数据约72.7%episode物理终止，数据可训练动力学，但不是64k条成功运动示范。动作监督误差降低不代表闭环稳定。需要针对后退、低速起步、左转和运动后归零检查成功示范覆盖；仅扩大同分布失败数据或继续BC未必改善。

### 3. 后期策略退化，末轮基本站立也丢失

280轮仍有6/20完整通过，290轮只有2/20，300轮全体在2秒左右倾倒。末轮世界模型学生32步误差92.48mm/44.47°，明显大于280轮14.00mm/12.00°和290轮24.78mm/14.66°；单步误差仅0.79mm/0.21°，不能代替32步/0.64秒准确性。

这支持“长时模型误差与策略退化相关”的判断，但无法仅由相关性确定先后：坏策略造成分布变化，也可能加重预测误差。不能把低world_loss或更负actor_loss当成真实运动改善。末轮learned终止在固定95条真实终止中漏判25条，analytic漏判0条，说明模型中存活估计偏乐观，可能令不稳定动作继续获得想象价值；尚未做终止模式训练消融，不能宣布它是唯一原因。

### 4. 停稳修复有局部效果，但没有解决全任务

多轮停稳数较高，例如220轮20/20、280轮12/20；相较R3末期“运动后持续摇摆、无人停稳”，R4出现较多能安静停住的场景。但220轮实际几乎没动，不能证明动态停车成功；280轮的通过也只覆盖零指令与右转。主要缺口是可靠运动接管与全指令稳定，末期又出现站立崩溃，不能继续只围绕停车惩罚调权重。

## 用户假设

摩擦、背隙、延迟等物理因素可能造成低速指令低于起步门槛，目标与实际运动不一致；速度跟踪奖励推动策略尝试更大动作，若缺乏稳定重心转移/迈步或模型预测偏差，可能导致失衡。该链条需要逐层验证，不能从目标未达标直接推断奖励导致跌倒。

## 已执行的方法

固定同一kissqy教师ONNX、关节映射和限幅；19种前后/纯转指令，每条件38个并行环境（两组配对相同初始状态副本），7个条件，共266条12秒轨迹。前2秒零指令，2–8秒运动并有0.5秒斜坡，随后归零；统计3–7秒实际机体系vx/wz、倾角、首次失败时刻、脚接触点切向速度。失败为倾角>55°或高度<0.07m/非有限。

## 如何解读与后续验证

- 若锁定背隙、取消延迟后小指令恢复运动，而单独加回某因素后停止，支持该因素提高起步门槛；若理想化基线仍不动，单靠这些物理因素解释不足，教师输入/训练出来的步态响应本身也需检查。
- 摩擦降低不必然改善，可能增加滑动；必须同时查看接触速度、倾角和实际推进。
- 本实验固定教师，不更新网络，因此能检验物理因素与教师闭环响应，但不能直接证明“奖励驱动学习→动作增大→失衡”。证明后半段需要固定初始化、数据与种子的短训练单因素对照，并比较奖励分解、动作、真实轨迹与想象轨迹。
- 此次不包含学习世界模型预测对照，原R4联合checkpoint已按要求删除；不能从教师扫描推断世界模型预测是否正确。
- 初始站姿起步与“已经走起来再减速”可能不同。本次网格从站姿出发，不足以描述滞回或任意连续调速；下一步需专门做持续运动中的减速/换向对照。采集器本次指令斜坡和并行执行方式与早期教师来源采集不完全相同，不能把两次数字差异全部归于单一物理参数。

原因是将目标由名义速度降低到教师实际均值后，站立与目标的误差也变小，站立得分升高；真实步态仍有0.16秒窗口内的摆动、侧向速度、航向漂移及动作成本。标定目标来自4秒均值，但奖励仍逐步评价短窗口误差，跟踪时间尺度仍未完全一致。不能因此简单取消平衡/侧滑约束，但这些实际排序已足以说明：仅标定目标，不重验真实步态排序，还不充分。

此前R5回归检查验证的是构造的理想恒速状态能否优于站立/名义速度，并未验证全部真实教师轨迹。该覆盖不足属于本次适配的缺口。这里的记录行为对照并非重训消融，不能证明它是所有指令不动的唯一原因；尤其转向、较快前进和弧线的记录教师回报仍高于站立，仍需结合初始化和模型误差解释。

### 失败原因：BC初始化与采集动作对当前状态缺少反馈接管

8次BC评估的非零目标完整通过全部0，最好候选250次也只是死区/零目标通过7/20、存活8/20。联合训练并没有从可靠行走策略起步。

检查代码：64k采集使用对应参考帧的录制动作加0.10rad噪声，动作不根据扰动后的当前状态重新查询教师；BC输入为该加噪轨迹的当前history，监督目标仍为对应参考帧的原动作（`targets[frames]`）。在摩擦、观测偏置、重心和动作噪声下，实际状态偏离原轨迹时，这个标签未必是当前状态所需的平衡恢复动作。这是明确的数据/代码事实，支持“预热不能可靠接管”的解释，但尚未通过更换BC数据的对照训练确认贡献。它不意味着物理转移不能用于世界模型学习。

## 奖励问题一：请求进展被指数误差再次缩放，存在时间漏洞

## 失败机制：事实与推断

1. **后期更新没有稳定保住平衡。** 280→300存活42→33、完整40→33，且存在两组随机化一过一倒，直接说明能力与物理条件相关、训练结果非单调。需要同一模型多种子和接触/倾角轨迹比较，才能分离参数敏感性与更新退化，不能凭当前日志指定某个摩擦或延迟为唯一原因。
2. **模型与存活估计有风险，但不是唯一解释。** 280轮学生32步误差9.17mm/7.33°，300轮17.05mm/11.12°，与后期退化相关；此前230轮误差更小却成绩差，说明低world_loss/误差并不充分。末轮固定校准集20条真实终止中learned漏判8条、analytic漏判0条，可能使想象过于乐观。这不是当前9次倾倒的逐一漏判统计，样本小，未做终止模式消融。
3. **奖励只修复了已覆盖的教师/站立排序，仍有其他漏洞。** 63条记录教师优于同指令站立的检查成立。现有CPU运动学反例表明正反往返可能净位移0却比站立得分高；真实替代行为探针6例中有1例纯转略高于弧线（约0.0125/步）。前者并未验证为MuJoCo可执行控制，后者是局部弱倒挂。没有280/300完整真实轨迹，不能认定学生已利用这些漏洞，但修复前应加入净位移闭合周期与弧线两轴同时完成的回归。

## 失败原因二：平均跟踪与精确调速仍有差距

400轮虽然按现有阈值全过，但一些均值仍偏离标定目标。例如原输入后退-0.15时目标-0.0700m/s，第一场景实际约-0.0499；原输入右转-0.50时目标-0.2433rad/s，第一场景实际约-0.3427；右弧线vx0.18/wz-0.30目标yaw约-0.1333，第一场景实际约-0.2217。直行部分场景仍有约0.1rad/s量级偏航。

原因之一是现有正式通过阈值采用平面各轴绝对误差<0.04m/s、yaw<0.15rad/s，对较小目标相对较宽。只作说明性附加重算，在正式通过者中再要求被请求运动轴相对误差≤25%，400轮剩33/42；没有改变原42/42成绩，也没有修改训练/验收。该重算不是新正式标准，零目标漂移仍按原绝对约束。

400轮瞬时平移/yaw RMSE为0.0556m/s、0.8003rad/s，而正式通过用3–7秒均值，二者不同。较高瞬时yaw误差可能包含步态往返摆动，不能只看均值就认为运动平顺；没有400轮50Hz完整学生轨迹，本次不能确定振荡频率、净位移或奖励利用方式。

## 失败原因三：局部模型/价值和目标竞争尚需隔离

400轮学生32步位置/姿态误差10.39mm/7.69°，较300轮17.05mm/11.12°改善。但380轮全败时该均值仍仅8.97mm/7.04°：平均预测误差没有揭示特定停车动作的风险，而且指标只统计相应存活窗口，不能替代跌倒附近的专项验证。

400轮固定校准集20条真实终止中learned漏判6条、误报4条；analytic漏判0条、误报1条。学习终止仍有乐观风险，但它不是当前在线30%漏判率，也不能由此认定380轮由终止模型单独造成。需要在失稳片段上比较预测状态、存活概率、末端价值与真实闭环。

已有CPU往返运动和部分弧线替代反例依然是R8公式风险，400轮通过未从数学上消除这些漏洞；但没有证据证明400轮学生正在利用它们。不能把存在奖励漏洞直接等同于本次失败因果，也不能用某个固定测试全通过宣称奖励已覆盖所有行为。
