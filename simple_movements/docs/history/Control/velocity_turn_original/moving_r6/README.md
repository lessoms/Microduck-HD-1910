## 当前版本R6：仅13组有效运动指令

已按用户确认的方案迁移训练数据与接口：排除零指令、教师不动的直行±0.05/±0.10与纯转±0.30，并暂不加入边界左弧线vx0.18/wz0.30、未经独立验证的连续变速/换向中间指令。允许13组包括前进/后退各3组、纯左右转各2组、前进右弧线2组和前进左弧线1组。原始教师来源保留用于标定与审计，不直接作为全部训练数据。

### 数据更新及删除

- 原64,000条中仅20,004条在指令上匹配。进一步要求对应参考帧位于39条合格教师轨迹的3–7秒稳定运动段后，实际保留12,060条原物理转移。其余51,940条不进入新数据集。
- 对保留片段的所有切口重新赋episode_id/episode_step，沿用原episode%10数据划分。每段末步标记truncated，不伪造terminated；物理失败末步继续保留。`next_state[t]`与`state[t+1]`逐段核对，8/32步窗口不跨缺口、原episode或参考段。
- 初筛发现部分指令的验证/测试32步窗口不足。固定同一个ONNX教师，针对缺口采集15条、每条180步，共2,700条新物理转移；保持摩擦0.5–1.2、观测偏置±0.01rad、CoM±2mm及动作噪声0.10rad。与旧录制动作重放不同，补采教师根据当前状态闭环查询动作。没有进行策略训练或DAgger策略迭代。
- 最终世界模型replay为14,760条，含224条真实终止转移。这些用于动力学/终止学习，不作为成功BC动作示范。实际条数不强求64,000。
- 新BC数据独立保存：39条稳定教师轨迹×200步=7,800条清洁history/action配对，其中前两次重复5,200条用于训练，第三次重复2,600条留出。每指令训练400/留出200条，不再把扰动后的history直接匹配原参考帧动作。留出重复为nominal物理，不代表独立域随机化泛化测试。
- 新参考库7,839帧（39段，每段200个有效重置帧和1个末端快照），全部来自已运动的教师状态；valid_reset与segment_end随新参考重建。保留完整执行器/延迟/背隙状态，原数据中的零速段不进入本版本参考。
- 连续性、有限值、指令/帧对齐及每指令32步窗口覆盖通过后，已删除旧 `replay/transitions.npz` 整个容器；其中有用的12,060条已复制到新数据，未保留旧64k重复副本。旧manifest/audit为历史记录并标记retired。原教师来源、标定JSON、历史日志保留。

新数据目录：`moving_r6/replay/`；清洁BC：`moving_r6/bc_teacher.npz`；参考：`moving_r6/reference.npz`；审计：`moving_r6/audit.json`；删除清单：`moving_r6/old_data_cleanup.json`。

### 代码与验收适配

- `velocity_joint_recipe.py`只接受这13组运动指令，其他/死区指令在训练分组入口报错；采集和BC由原7组改为13组平衡采样，BC仍保持448样本/次。
- 自适应重置仍使用原方法和配额，但仅访问新参考内的有效运动快照。真实与想象奖励继续使用教师实际响应标定；版本为 `teacher_response_moving_r6`，拒绝旧目标版本预热权重。
- BC从清洁教师的当前history与相应action学习，世界模型从独立物理replay学习；13组池都存在，输入仍为原始速度/转速指令。
- 评估改为13组指令×2随机化=26场景，各自从匹配的**运动中教师快照**开始，持续12秒执行相同有效指令。3–7秒均值与教师实际目标比较，平面每轴误差<0.04m/s、yaw误差<0.15rad/s，要求存活。没有零输入、死区任务，也不在最后阶段下发零指令；本版本**不检验从站姿起步、停车、任意变速/换向**。`full_sequence`现在仅表示运动保持与跟踪通过，`stop_evaluation_enabled=false`，不能直接与旧版包含停车的full_sequence比较。
- 每10轮保存/评估保留。world/critic/联合优化原SuperMimic方法、32步想象与网络尺寸不变；BC数据和分组、任务范围和评估流程按本次需求适配。

GPU接口短测已完成：4,096条独立短测采集、world/critic/actor各2次预热、10个并行控制步、640条在线转移、4次联合更新循环。26场景均为非零标定目标，死区指令拒绝测试通过。短测只验证接口，未证明策略会走；正式预热/300轮尚未启动。记录见 `moving_r6/verification.json`。
