## 速度惩罚离线对照

将官方示范整体延迟 80 ms，用当前帧计算速度惩罚时，前滚翻、起身、直走和转向分别有 96.7%、43.5%、100% 和 100% 的帧被扣分。按姿态在当前参考帧及之前 4 帧中选出最近的一帧，再用同一帧计算线速度和角速度误差，这组纯延迟对照的扣分全部归零。

对真实随机化中成功的教师轨迹，时序对齐后仍有至少 19.5% 的前滚翻恢复帧触发角速度扣分上限，坐下和起身分别至少有 6.0% 和 3.1%。教师数据保存了机身坐标系的角速度和重力方向，因此使用误差上下界估计。第 110 轮学生跑完的 18 个场景中，末秒线速度和角速度峰值的中位数分别为 0.077 m/s 和 2.123 rad/s。接管后，20 个通过场景的对应值为 0.0023 m/s 和 0.0246 rad/s。审计只保存了汇总，无法重算逐场景累计扣分。走路只做了示范延迟对照。

### 奖励实现

- 原有奖励和停滞惩罚保留。新增项逐步比较实际与参考的机身速度向量。线速度容差为 `0.02 + 0.2 × 参考线速度模长` m/s，角速度容差为 `0.20 + 0.2 × 参考角速度模长` rad/s。误差超出容差后线性扣分，分别在再超出 0.04 m/s 和 0.40 rad/s 时达到单项上限 −0.15。
- 在对齐后的参考帧计算速度差。扣分权重由当前参考帧为中心的 11 帧（0.22 秒）窗口决定。分别将参考线速度 RMS 除以 0.02 m/s、角速度 RMS 除以 0.20 rad/s，取两者的较大值。比值不超过 1 时权重为 100%，从 1 到 3 线性降权，达到 3 后为 25%。离线重算中，成功教师的翻滚、恢复、坐下、起身四段角速度平均扣分上界分别下降约 73%、50%、64%、64%，前滚翻最后一秒仍保持全权重。
- 真实仿真、离线 replay 奖励重算和世界模型想象共用该项。自适应 reset 的一秒难度得分继续使用原有跟踪分量。验收仍按原速度、高度和倾角门槛执行。

### 回退原因与后续验证

记录呈现出明显的联合更新不稳定。第 220 轮完整通过 17/20，随后第 230、240 轮降至 0/20。第 270 轮通过 16/20，紧接着第 280 轮又降至 0/20。第 270 与 280 轮属于同一次连续运行，这次回退发生在运行内部。第 180 轮后重启又在第 190 轮降至全程 0/20，重启时重新积累在线 replay 与 reset 统计也可能影响更新分布，但日志不足以量化其贡献。

代码中 actor 沿世界模型想象轨迹优化回报，并使用目标 critic 的末值，联合阶段 critic 也从想象轨迹更新。模型误差、终止概率误差和 critic 价值偏差都可能使更新偏离真实仿真中的成功动作。目前评估记录支持“成功策略会在后续更新中退化”，具体归因于世界模型还是 critic 仍需受控对照。旧坐站任务的 critic 结论不能直接作为本次前滚翻的归因证据。

## 前滚翻训练实现更新

训练入口现已接入以下五项修改。

- 检查点保存在线 replay、环形缓冲写入步数、reset sampler 统计、下一 episode 编号及 Python、NumPy、PyTorch、CUDA 和环境采样器随机数状态。续训保留已有 replay，当前仿真 episode 从新 reset 开始。旧检查点没有保存在线数据，首次迁移时会打印提示并建立新缓冲。
- 想象轨迹增加小黄鸭相对参考姿态、高度、编码器越限和根部位置误差的平滑终止概率，通过 `--termination-mode analytic` 启用。旧检查点默认继承学习终止头，新检查点继承保存的模式。`--termination-mode learned` 可显式选择学习终止头。真实 MuJoCo 的终止规则提供评估标签，两个终止方式都会输出分阶段校准统计。
- 启用 `--speed-penalty` 时，困难片段得分加入归一化速度扣分，默认权重 0.25，可通过 `--reset-speed-weight` 在 0–1 内调整。得分仍保持在 0–1，跌倒扣分不参与这一难度得分。
