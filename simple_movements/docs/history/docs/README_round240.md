# Microduck HD-1910 SuperMimic 第 240 轮实验

> **归档状态**　目录保留第 240 轮策略和 MuJoCo 推理依赖。历史采集、训练和评估文件已按要求清理，下面的实验配置和数字作为历史记录。单独的世界模型与 critic 预热权重在清理前已未找到。

本实验用一条 13 秒的参考动作训练 Microduck 从站立起步，前进约 20–30 cm，左转约 90°，最后停稳。第 240 轮在固定 20 个 MuJoCo 开发场景中，前进和转角均为 20/20 达标，包含足部接触和停稳在内的完整筛选为 7/20。当前可直接加载第 240 轮策略在 MuJoCo 实时查看。

策略输出关节位置偏移。执行接口先对动作限幅，再加默认关节位置，并按各关节允许范围裁剪目标。策略反馈读取电机关节与被动齿隙关节的位置之和。BAM 电气和摩擦模型使用电机侧速度。HD-1910 参数来自项目现有模型，尚未针对用户手头的实体舵机重新辨识。

### 域随机化怎么做

**采样时机。** 每次 reset 时，只给正在重置的并行环境重新采样。每个环境抽 1 个摩擦系数、14 个关节读数偏差和 3 个躯干质心偏移。每个数由独立的均匀随机数生成，整组参数在该 episode 内保持固定。

```python
# N 是本次 reset 的环境数。rand 生成 [0, 1) 的独立均匀随机数。
mu = 0.5 + 0.7 * rand(N)                 # 足底滑动摩擦系数
bias = -0.01 + 0.02 * rand(N, 14)        # 关节位置读数偏差，rad
com = -0.002 + 0.004 * rand(N, 3)        # 躯干局部质心偏移，m
```

1. **足底摩擦。** 对每个待重置环境，把左右足碰撞体的 `geom_friction` 从模型编译时的标称值复制回来，再把第 0 项（滑动摩擦）替换为该环境采到的 `mu`。两只脚共享一个系数，扭转摩擦和滚动摩擦保留标称值。例如抽到 0.65，该 episode 左右足的滑动摩擦均设为 0.65。MuJoCo 在后续接触计算中使用这些参数。
2. **躯干质心。** 在躯干局部坐标系的 x、y、z 轴各采一个 ±2 mm 的偏移。将躯干惯性坐标系原点设为 `body_ipos = 标称 body_ipos + com`，使质心相对躯干移动。总质量、主惯量和主轴方向保持原值。每次都从标称质心计算，偏移不会随多次 reset 累加。
3. **关节标定偏差。** 给 14 个受控关节各采一个 ±0.01 rad 的固定偏差。每帧送给策略的位置读数为 `q_obs = q_motor + q_backlash - q_default + bias`。偏差只进入策略观测，仿真真实关节位置、关节速度、关节目标和力矩仍由原控制与物理模型计算。采集时标准差 0.15 rad 的探索噪声另加在策略动作上，逐帧传感器噪声关闭。

**参数如何生效。** Reset 先采样并暂存新参数，再在 reset 事件里写入对应环境的物理字段并重算相关模型常量。随后恢复所选参考帧的位姿、速度和舵机记忆，在新物理参数下建立接触状态。其他环境继续运行各自已采样的参数。

**训练如何使用。** 每条 replay 转移保存对应 episode 的 18 维上下文，按 `[足底滑动摩擦, 14 个关节偏差, 躯干质心偏移 x/y/z]` 排列。世界模型用它区分不同仿真条件，想象 rollout 则沿用起点对应的参数。策略通过带偏差的关节读数和实际运动反馈适应这些变化。

参考录制使用标称条件。64,000 条初始数据采集、在线联合训练、第 240 轮的随机化评估和实时演示都使用上述 reset 随机化。

## 2. 参考运动与原始数据

现成的 kissqy walk 策略在当前 HD-1910 仿真里执行速度和朝向指令，连续录制 13 秒、651 帧。0–2 秒站立，2–5 秒前进，5–10 秒左转，10–11 秒修正朝向，11–13 秒停稳。标称录制转向前前进 26.56 cm，最终转角 90.35°。参考文件保存根部和各关节的位姿、速度、身体状态、足底接触和执行器记忆。

原始 replay 由一个**随机初始化的采集策略**生成，64 个环境各采 1,000 条，共 **64,000 条 20 ms 单步转移**，涉及 1,502 个 episode。采集策略每次从参考帧 0–649 均匀抽取起点，恢复该帧的机器人位姿、速度、齿隙和延迟队列等状态，并在当前随机化参数下重建接触求解状态。接管后，采集策略根据本体观测和未来参考输出动作，加入标准差 0.15 rad 的高斯探索噪声，限幅后交给 MuJoCo 执行。教师策略提供参考和 reset 快照，采集策略和后续 SuperMimic 策略均从随机权重开始。

每条转移保存当前状态、实际执行动作、下一状态、随机化上下文、参考帧、观测历史、奖励、终止或截断标签。另存原始策略动作、噪声和最终位置目标。世界模型状态为 291 维，包含根部运动、28 个电机与齿隙关节状态、执行器目标和延迟历史、力矩及求解器历史。物理终止前的最后状态先写入，再 reset。

## 3. 世界模型和 critic 预热

1. **世界模型更新 5,000 次。** 以真实状态开始，每批 128 个连续 8 步窗口，后续逐步使用模型自己的预测。动力学损失使用归一化状态的加权 Huber 损失，另加末步 FK 身体位置损失。终止分类使用独立均匀抽取的真实状态转移。训练结束按固定验证结果选出 **第 4,800 次世界模型权重**进入联合训练。
2. **critic 更新 1,000 次。** 从随机权重开始，每批 128 个真实起点，用最多 32 步连续轨迹的多步回报拟合价值。物理终止后价值归零，截断按原因决定是否 bootstrap。使用固定归一化和慢更新 target critic。
3. 策略在联合训练第 0 轮仍是随机初始化权重。预热后的世界模型、critic、优化器和归一化进入在线阶段。

来源：训练入口（原路径 `../scripts/train_old_aligned.py`） · 预热评估记录（原路径 `old_aligned_world_stages.md`）

## 4. 联合训练配置和运行方式

| 参数 | 设置 |
| --- | --- |
| 并行环境 / 每轮控制步 | 64 / 50 |
| 本体历史 | 10 帧 × 48 维 |
| 未来参考 | 10 个采样点 × 44 维，未来偏移 1、2、5、10、15、20、25、30、40、50 步 |
| 策略 | 目标编码器和动作 decoder 使用 2048、1024、512、256 隐藏宽度，latent 32 维 |
| 世界模型 | 2048 × 3 隐藏层，批次 128，8 步拟合窗口 |
| 策略更新 | 批次 32，32 步想象轨迹 |
| critic | 256、128 隐藏层，输入 753 维，含完整状态、随机化上下文、未来参考和根部误差 |
| Adam 学习率 | 世界模型 0.0003，策略 0.0001，critic 0.0003 |
| 回报 | 折扣 0.99，GAE λ 0.95，target critic 更新系数 0.005 |

每 5 个并行控制步执行 2 次联合更新循环。每次先更新世界模型 10 次，再冻结世界模型权重，展开 32 步想象轨迹。策略通过跟踪奖励、预测存活概率和末端价值反向传播。critic 用同批想象轨迹的 GAE 目标训练 5 个 epoch，每个 4 个 minibatch。真实 MuJoCo 仿真持续生成新转移，更新滚动 replay。

第 240 轮累计 **12,000 个并行控制步、768,000 条新增转移、48,000 次世界模型更新、4,800 次策略更新、96,000 次 critic minibatch 更新**。预热及原始 64,000 条数据另计。

各列是独立检查，提前终止的场景仍须通过“完整运行”才能计入成功。第 240 轮额外做了控制帧足部和接触复核，20/20 通过双脚抬脚检查，左右脚在这组测试中的最大离地高度约为 10.5 mm 和 14.2 mm。所有物理检查同时通过仍为 **7/20**，主要限制是停稳。控制帧接触重建可能漏掉子步瞬时接触。

第 240 轮固定验证窗口的世界模型位置 RMSE 为 **0.49 mm / 4.51 mm / 40.64 mm**，对应 1 / 8 / 32 步。姿态 RMSE 为 **0.44° / 3.61° / 22.82°**，该轮世界模型未通过固定物理误差门槛。第 250 轮转向退步，因此保留第 240 轮作为当前可视化候选。成功率来自反复使用的开发场景，独立随机化测试和真机验收尚待进行。阶段结果同时包含训练步数增加和配置变化，无法单独归因到某一项改动。
