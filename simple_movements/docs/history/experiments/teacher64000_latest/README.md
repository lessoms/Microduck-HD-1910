# Microduck HD-1910 三条动作链的新旧训练对比

本目录组织行走转弯、坐下起立、前滚翻起身三条动作链。本文依据 docs 中的历史实验记录和当前脚本，对比训练方法、参考运动、数据来源及评估方式。行走实验已记录至第 200 轮，前滚翻实验已记录至第 400 轮，本文依据正式日志、数据清单和检查点补充结果。坐站结果已记录至第 140 轮，后续轮次继续预留。已确定的计划配置列在配置表中。

## 前后运动与左右转向联合任务

当前速度控制仅保留 [Control/velocity_turn_original](../../Control/velocity_turn_original/README.md) 这一套联合任务。它沿用本页原网络规模、5,000/1,000/2,000次预热、32步想象、critic bootstrap/GAE和联合更新节奏；指令、任务奖励、重置采样阶段及评估适配为当前机体前后速度vx和yaw转速wz，不加入在线教师纠偏。

新的64,000条前后＋转向加噪数据已完成并通过审计，正式预热与200轮联合训练已完成，最好170轮完整通过5/20、末轮2/20，尚未达到可靠控制目标。旧的仅前后速度任务和简化试验已清理，入口统一为 `Control/run_velocity_turn_recipe.sh`。下面原固定动作链历史结果与代码仍是方法来源及共享依赖，不是联合速度任务的完成记录。

### 4.6 训练结果分析与退化原因

第 40 轮首次出现完整动作通过，为 14/20。第 120 轮达到固定组最高值 20/20，最终第 200 轮为 11/20，下降 45 个百分点。20 次固定评估中有 8 次完整通过为零，分别为第 10、20、30、60、80、130、160、180 轮。训练后段也持续波动。

失败可按已记录指标分为以下几类。

| 轮次 | 观察到的失败 |
| --- | --- |
| 60、80 | 20 个场景均提前终止 |
| 90 | 19/20 达到行走转向要求，末段站稳只有 6/20，完整通过 6/20 |
| 110 | 20/20 跑完并站稳，平均转角 63.85°，完整通过 3/20 |
| 130 | 14/20 跑完并站稳，平均转角 134.30°，完整通过 0/20 |
| 160 | 20/20 跑完并站稳，平均转角 59.51°，完整通过 0/20 |
| 180 | 12/20 跑完并站稳，平均转角 141.74°，完整通过 0/20 |
| 200 | 20/20 跑完并站稳，行走转向达标 11/20，完整通过 11/20 |

最终第 200 轮的站稳已达到 20/20，限制完整通过率的是行走/转向条件，平均前进为 27.03 cm、平均转角 109.40°。逐场景分解仍需复测，单个总体均值无法确定每个失败场景的距离与转角分别是否达标。

代码层面存在以下与波动相关的机制。

1. Actor 输入包含角速度、重力方向及关节历史，未来目标相对于参考当前姿态编码。实际根部航向误差没有直接输入 actor，累计偏航后的闭环纠正能力受到限制。
2. 第 120→130 轮间继续更新 actor 200 次、世界模型 2,000 次。更新只有梯度范数裁剪，策略与正在变化的动力学模型持续共同演进，完整动作评估只记录结果。
3. 每次世界模型拟合使用连续 8 步，actor 沿模型展开 32 步并使用 critic 末端价值。多步动力学误差与价值估计误差均可能影响策略梯度。
4. Actor batch 为 32，采样起点来自离线/在线混合 replay。局部想象回报与整条 13 秒动作链的最终判据之间存在差距。

此前第 120/130 轮定点复测分别得到 20/20 和 1/20，正式评估分别为 20/20 和 0/20。复测中第 130 轮存活场景多数转到 116–139°，5 个场景在 9.36–10.14 秒触发相对姿态阈值。该阈值使用相对四元数的完整旋转角，包含航向误差，提前终止需要结合姿态及接触轨迹解释。

### 6.9 退化原因的证据与边界

**策略发生了显著变化。** 从第 380→400 轮继续执行 400 次 actor 更新、4,000 次世界模型更新和 8,000 次 critic minibatch 更新。在相同的第 380 轮 replay 观测历史和未来目标上，对两个策略做前向比较，结果如下。数值是按动作尺度换算后、关节目标限位裁剪前的目标偏移差，不能直接作为实际关节运动幅度。

| 阶段 | 比较状态数 | 目标偏移差 RMS |
| --- | ---: | ---: |
| 初始站立 | 46 | 0.145 rad，约 8.3° |
| 翻转 | 183 | 0.321 rad，约 18.4° |
| 恢复 | 114 | 0.162 rad，约 9.3° |
| 停稳 | 681 | 0.139 rad，约 8.0° |

翻转阶段的策略输出变化约 0.321 rad，足以表明网络在已有成功策略之后仍被明显改写。当前更新采用梯度范数裁剪，未按真实完整动作通过率约束更新幅度或自动回滚。评估每 10 轮进行一次，策略仍在两次评估之间持续优化想象回报。

**世界模型误差具有阶段性。** 为固定输入分布，本次使用第 380 轮同一批独立学生轨迹、相同起点和动作序列，分别检查三个世界模型的 32 步预测。

| 阶段 | 旧第 220 轮模型位置 RMSE | 新第 380 轮模型位置 RMSE | 新第 400 轮模型位置 RMSE |
| --- | ---: | ---: | ---: |
| 翻转 | 83.30 mm | 43.69 mm | 42.05 mm |
| 恢复 | 17.59 mm | 10.23 mm | 17.38 mm |
| 停稳 | 12.05 mm | 17.47 mm | 8.65 mm |

新模型 380→400 轮的恢复位置误差增大，翻转和停稳位置误差有所下降。新第 380 轮模型在这批轨迹上的翻转姿态 RMSE 约 44.5°，第 400 轮约 31.5°，两者仍存在明显的长时段误差。策略表现与单个模型误差指标并非一一对应。共享轨迹来自新第 380 轮策略，旧模型在其上的误差也受数据覆盖差异影响。

**终止概率仍有局部误判。** 第 350 轮学生验证轨迹的翻转阶段有 7 次真实终止，学习头在 0.5 分类阈值下全部漏判。第 400 轮翻转阶段 5 次真实终止中漏判 1 次，并有 3 次误报。该记录支持继续校准想象中的风险估计，尚不能单独解释整段退化。

**采样与 critic 的影响仍需受控实验。** 第 380 和 400 轮困难分布的最大单段概率均为 0.25。这个统计无法确定困难采样对退化的贡献；critic 末值也尚未与同起点真实回报做排序对照。由于 actor、世界模型和 critic 同时更新，现有结果支持“成功策略在持续联合更新中发生明显漂移”，具体是哪一种梯度偏差驱动，需要固定模型、固定 critic 或限制策略更新的对照分支。

新旧方案还同时存在 actor 数据来源、速度惩罚启用时机和 critic 历史输入等差异。旧方案使用额外闭环教师 BC，并在原奖励训练第 150 轮后加入速度惩罚及 critic 校准；新方案使用 replay 状态对应的预录动作，从冷启动即启用速度回报与速度困难度。现有单次运行不能量化各项改动的独立贡献。

当前优先复核的候选为第 380 轮，最终第 400 轮的历史记录用于回退对照。继续增加轮次的收益需要真实评估确认；训练迭代数本身不构成完整动作能力的保证。
